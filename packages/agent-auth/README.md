# CinaAuth Agent Auth Plugin

Agent identity, registration, approval, and capability-based authorization for
[CinaAuth](https://www.cinagroup.com).

## Installation

```bash
pnpm add @cinaauth/agent-auth
```

## Documentation

See the [Agent Auth documentation](https://www.cinagroup.com/docs/plugins/agent-auth).

The protocol implementation is provided by the MIT-licensed
[`@better-auth/agent-auth`](https://github.com/better-auth/agent-auth) package and
is adapted here to CinaAuth's package namespace and plugin types.
